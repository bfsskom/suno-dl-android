# suno-dl Android

Unduh lagu [Suno](https://suno.com) **publik** ke HP Android — hasilnya file **M4A** + sampul `.jpeg`.

Butuh **Android 8.0** atau lebih baru (± 1,6 MB).

## Unduh & pasang

1. Buka halaman **[Releases](https://github.com/bfsskom/suno-dl-android/releases/latest)** → unduh `app-release.apk`
2. Buka file APK → pilih **"Izinkan dari sumber ini"** → **Pasang**

> Play Protect mungkin memperingatkan — pilih **"Tetap pasang"** (wajar untuk aplikasi di luar Play Store).

## Cara pakai

1. Salin tautan lagu Suno (contoh: `https://suno.com/s/abc123`)
2. Buka **suno-dl** → tekan **Tempel** → pastikan muncul `✓ Tautan valid`
3. Tekan **Unduh** → hasil tersimpan di **`Download/suno-dl`** (file `.m4a` + `.jpeg`)
4. Setelah selesai tersedia tombol **Buka folder** dan **Putar**

Ingin berhenti di tengah jalan? Tekan **Batal** — file sementara dibersihkan otomatis.

## Keamanan & privasi

- Hanya meminta izin **INTERNET** — tanpa akses kontak, lokasi, kamera, maupun penyimpanan penuh
- Tidak ada akun, telemetry, analitik, atau iklan — tidak ada data Anda yang dikirim ke pihak ketiga; aplikasi hanya mengambil lagu yang **Anda minta** dari server Suno
- Hasil unduhan tetap di HP Anda; uninstall aplikasi tidak menghapusnya

## Catatan

- Hanya untuk lagu **publik**. Hormati Terms of Service Suno dan hak pembuat lagu; jangan redistribusi hasil unduhan. Tidak berafiliasi dengan Suno.
